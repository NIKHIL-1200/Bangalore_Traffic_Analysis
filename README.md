# Bangalore Traffic Analysis using Python 🚦

## 📌 Project Overview

The **Bangalore Traffic Analysis** project explores traffic patterns across different areas of Bangalore using Python. The objective is to analyze congestion levels, traffic volume, travel time, environmental impact, and public transport usage to uncover meaningful insights that support better traffic management and urban planning.

The project applies data cleaning, exploratory data analysis (EDA), and data visualization techniques to transform raw traffic data into actionable business insights.

---

## 🎯 Objectives

* Analyze traffic patterns across Bangalore.
* Identify high-traffic and high-congestion areas.
* Study the relationship between traffic volume and average speed.
* Evaluate the impact of weather on traffic conditions.
* Analyze travel time trends across different locations.
* Understand public transport usage across Bangalore.
* Perform correlation analysis to identify relationships between key traffic metrics.

## 📊 Business Questions Answered

### 1. Which Bangalore areas have the highest traffic volume?

Identified the busiest areas based on total traffic volume.

### 2. Which roads/intersections experience the highest congestion?

Analyzed congestion levels across major roads and intersections.

### 3. What is the average traffic speed across different Bangalore areas?

Compared average vehicle speed to identify slow-moving traffic zones.

### 4. Which month experiences the highest traffic volume?

Studied monthly traffic trends to identify seasonal traffic patterns.

### 5. How do weather conditions affect traffic volume and average speed?

Analyzed the influence of different weather conditions on traffic flow.

### 6. Which Bangalore areas have the highest Travel Time Index?

Identified locations where commuters experience the greatest travel delays.

### 7. Is there a relationship between traffic volume and average speed?

Used scatter plots and regression analysis to study the correlation.

### 8. Which Bangalore areas have the highest environmental impact due to traffic?

Analyzed pollution-related indicators associated with traffic.

### 9. How does public transport usage vary across Bangalore areas?

Compared public transport adoption across different locations.

### 10. What is the relationship between key traffic metrics?

Performed correlation analysis using a heatmap to understand relationships between traffic volume, travel time, speed, incidents, and road utilization.

---

## 📈 Key Insights

* Several Bangalore areas experience consistently high traffic volume.
* High traffic volume is associated with lower average vehicle speed.
* Weather conditions significantly influence traffic flow.
* Some areas experience considerably higher travel delays.
* Public transport usage varies across different regions.
* Strong relationships exist between traffic volume, travel time, and congestion.

## 🚀 How to Run the Project

1. Clone the repository.

```bash
git clone https://github.com/your-username/Bangalore_Traffic_Analysis.git
```

2. Navigate to the project directory.

```bash
cd Bangalore_Traffic_Analysis
```

3. Install the required libraries.

```bash
pip install -r requirements.txt
```

4. Open the Jupyter Notebook.

```bash
jupyter notebook
```

5. Run all cells in **Bangalore_Traffic_Analysis.ipynb**.
